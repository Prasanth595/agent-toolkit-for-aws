# Clarify AI requirements

Invoke `scripts/bma-runtime.py execute --request -` before writing direct preferences or returning a delegated result. Direct mode submits the planned `preferences.json` write. Delegated AI-only mode (`delegated_route: ai_only`) submits BMA-owned draft and final preferences writes through the same command. Delegated combined mode (`delegated_route: combined`) submits no preferences write; it validates the typed result before the GCP assembler receives it, and the GCP assembler performs the single `preferences.json` write. Use the returned state decision, consent trace, selected writer, and write audit as the phase contract.

Direct mode loads `references/phases/clarify/clarify-ai-only.md`. Delegated combined mode loads `references/phases/clarify/clarify-ai.md`, follows `references/shared/bma-ai-clarify-result.md`, validates one result against `references/runtime/bma-ai-clarify-result.schema.json`, and returns it without writing preferences. Both modes preserve the current `references/shared/schema-preferences.md` shape and use the neutral region authority in `references/runtime/bedrock-region-map.json`. Load the applicable canonical fragments: `references/vendored/clarify/clarify-availability.md`, `references/vendored/clarify/clarify-compliance.md`, `references/vendored/clarify/clarify-cost-appetite.md`, `references/vendored/clarify/clarify-multicloud.md`, and `references/vendored/clarify/clarify-region.md`.
