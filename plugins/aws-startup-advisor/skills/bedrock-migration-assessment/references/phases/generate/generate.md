# Generate migration support artifacts

Invoke `scripts/bma-runtime.py execute --request -` with the current state and explicit Execute decision before any Generate write. Submit `generation-ai.json` and each `ai-migration/` output through its guarded write list. Submit final-document contributions through its assembly list so duplicate IDs, order keys, targets, owners, existing final outputs, and last-write-wins attempts fail before publication. Each final-document assembly also carries its complete `document` (and `report_mode` for HTML targets); see the report assembly ABI in SKILL.md.

Generate is opt-in. Load `references/phases/generate/generate-ai.md`, then `references/phases/generate/generate-artifacts-ai.md`. Build typed sections from `references/report-sections/ai-guide.md`, `references/report-sections/ai-readme.md`, `references/report-sections/ai-decision-report.md`, and `references/report-sections/ai-migration-report.md`; apply `references/shared/validate-artifacts.md` and `references/shared/validate-migration-report.md`. BMA alone writes neutral plans and `ai-migration/`; the outer controller owns final assembly and state.
